# Cancer Awareness & Support – Web Page  
A simple, responsive web page built as part of an internship assignment.  
The page aims to spread awareness about cancer, offer support, and provide a way for users to get in touch.

## 🌟 Features
### ✔ Landing Page  
- Clean header section  
- Inspirational message  
- Full-width banner image  

### ✔ Contact Form (Frontend Only)  
- Fields: Name, Email, Message  
- No backend required  
- Simple and user-friendly form UI  

### ✔ Real-Time Quotes (Bonus Feature)  
- Fetches an inspirational quote from the public **Quotable API**  
- Displays a new quote each time the page loads  

### ✔ Fully Responsive  
- Works on mobile, tablet, and desktop  
- Uses pure HTML + CSS  

---

## 🛠 Tech Stack
- **HTML**
- **CSS**
- **JavaScript (for API call)**

No frameworks or backend required.
